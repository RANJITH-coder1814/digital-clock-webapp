# digital-clock-webapp
A simple and responsive Digital Clock Web Application built using HTML, CSS, and JavaScript. The clock displays the current time in real-time and updates every second.  This project is great for beginners who want to understand JavaScript Date objects and DOM manipulation.

A simple Digital Clock built with HTML, CSS, and JavaScript that displays the current time and updates every second.

## Features
- Real-time clock
- 12-hour format with AM/PM
- Responsive design
- Beginner friendly project

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository
2. Open `index.html` in your browser

Displays the current time with a clean digital clock interface.
